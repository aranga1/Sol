Capabilities.

Everything Sol can do — iOS features, what gets indexed, and the full CLI reference.

iOS app

Ask your vault

Type or speak any question. Sol uses semantic search (FAISS + Ollama embeddings) to find the relevant notes and answers in plain language — with links back to the source.

Voice notes

Tap the mic, speak, done. WhisperKit transcribes entirely on-device — no audio ever leaves your phone. The transcription is saved as a Markdown note to your Obsidian vault.

Text & markdown notes

Quick-capture panel with Markdown formatting and tag autocomplete pulled from your vault. Notes land in Obsidian instantly via the daemon's Obsidian URI integration.

Calendar

Ask about your schedule in natural language — "what do I have this week?" Sol reads from EventKit and understands relative time. You can also say "schedule a meeting tomorrow at 2pm" and Sol opens the calendar editor pre-filled.

Push notifications

Send yourself a notification from your Mac with sol notify. Three types: info, warning, and update. Useful for reminders, automation scripts, or any background task output.

Conversation history

Every query session is saved locally. Browse past conversations from the sidebar, pick up any thread, and re-run queries against an updated vault.

Fully local & private

The daemon runs on your Mac. LLM inference runs via Ollama — no API keys, no cloud calls. Your notes never leave your network. Sol connects over Tailscale so it works anywhere on mobile data.

QR connection setup

Run sol qr on your Mac to print a QR code to the terminal. Scan it in the Sol app to configure your Tailscale IP, port, and API key in one tap — no manual entry.

What gets indexed

Sol watches your vault directory and automatically indexes everything below. New or changed files are picked up within seconds by the background watcher.

Markdown
.md

The native format. Front matter, headings, tags, wikilinks, and callouts are all parsed. Text is split into overlapping chunks for retrieval.

PDF
.pdf

Full text extraction via pypdf. Drop PDFs anywhere in your vault — research papers, articles, receipts — and ask about them naturally.

Word documents
.docx .doc

Body text and paragraphs extracted from Word files. Useful for imported documents, reports, or notes originally written outside Obsidian.

Spreadsheets
.xlsx .xls

Cell contents from all sheets are extracted and indexed as searchable text — handy for tracking data stored in Excel format alongside your notes.

Images
.jpg .jpeg .png .gif .webp

Images are described by a local vision model (llava via Ollama). The description is embedded and indexed — so you can search for "photo of the whiteboard from Tuesday" and find it. Run sol index-images to process new images.

Calendar events
EventKit

All calendars on your Mac are synced every 60 seconds via EventKit. Events include title, date/time, location, and notes. Ask "what meetings do I have this week?" and Sol answers directly from the index — no FAISS search needed for date queries.

CLI reference

The sol command is installed to ~/.local/bin/sol by the installer. It controls the daemon and provides utility shortcuts.

Daemon control

sol status

Print the current state of the daemon, Ollama, Tailscale, and your vault. Shows the running port, connected Tailscale IP, Ollama model, and note count.

sol start

Start the daemon via launchd. No-op if it's already running. The daemon binds to 0.0.0.0:8765 so it's reachable from your iPhone over Tailscale.

sol stop

Stop the daemon. The LaunchAgent will restart it automatically on next login unless you run this each time.

sol restart

Unload and reload the LaunchAgent. Use this after editing config or after installing updates manually.

sol logs

Tail ~/.sol/daemon.log in real time. Ctrl-C to exit. Useful for debugging indexing, query errors, or calendar sync issues.

Updates

sol update

Pull the latest code from GitHub, reinstall the solidrag package into the daemon's venv, update all dependencies, and restart the daemon. Run this whenever a new version is released.

sol update-ios

Check GitHub Releases for a new iOS build. If a newer version is available, prints an OTA install URL and renders a QR code you can scan with your iPhone.

Configuration

sol config

Open ~/.sol/config.json in your $EDITOR. Useful for changing vault_path, ollama_model, vision_model, or the system prompt. Run sol restart after saving.

sol qr

Regenerate the iPhone connection QR code using the current Tailscale IP, port, and API key. Run this after rotating your API key or if you sign into a different Tailscale account.

Indexing

sol index-images

Scan the vault for images not yet in the index. Each image is sent to the local vision model (llava) for description, then embedded and added to FAISS. Also prunes entries for deleted images. Reloads the daemon on completion so the new entries are immediately queryable.

Images are not indexed automatically — run this after dropping new images into your vault.
sol index-calendar

Trigger an immediate EventKit sync without waiting for the automatic 60-second polling cycle. Useful after adding calendar events you want to query right away.

Calendar events sync automatically every 60s while the daemon is running. Use this only when you need an instant update.

Notifications

sol notify "Title" "Body text" [type]
info warning update

Queue a push notification to your iPhone. The app must be in the foreground (or recently backgrounded) to receive it. The optional third argument sets the notification style — defaults to info.

Examples
sol notify "Backup done" "Time Machine finished"
sol notify "CI failed" "Build #42 on main" warning

Maintenance

sol uninstall

Run the uninstall script. Stops the daemon, removes the LaunchAgent plist, and cleans up installed files. Your ~/.sol/config.json and vault are untouched.
